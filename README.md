# AI 行业情报库

集中查看和对比主流 AI 公司的模型、融资、定价和动态，并按能力赛道比较 AI 产品、看懂行业新词。

每条信息都附来源，查不到的字段写「未查到」。数据由定时任务每天检索、核对后更新。

## 功能

- **公司列表与横向对比**：12 家国内外 AI 公司，支持 2–4 家并排比较
- **模型详情与演变**：主力模型分类参数，历代模型存档
- **商业定价与功能矩阵**：会员档位、API 价格、12 项功能
- **动态时间线**：公司动态和行业事件，可按类型和关注方向筛选
- **新词雷达**：技术新词的大白话解释、演变线和产品启示，可标记「我已知道」
- **能力地图**：8 条赛道的产品和按赛道定制的对比矩阵

## 本地打开

下载后双击根目录的 `index.html`。不需要安装依赖或启动服务器。
